# KOISHOGI 教材棋盤

將棋棋譜閱讀、擺盤、教材標記與棋圖匯出工具。直接下載並用瀏覽器開啟 `index.html` 即可，無需安裝依賴或連線。

## 操作

- 點棋子，再點目的格走棋；可升變時顯示選擇。
- 點持駒，再點空格打入；吃子自動進持駒並換手。
- 拖曳画箭頭；Ctrl／Command 點格畫圈；Shift 拖曳畫框。
- 右鍵點棋格，直接升變、翻面、移除、放棋或修改標記。
- 開啟、拖入 KIF／KIFU 檔案，或 Ctrl＋V 貼上完整 KIF。
- 點右側步數或按左右鍵瀏覽棋譜。
- 「存成圖片」下載 2400×2800 PNG；「配置與保存」可匯出 SVG 或可編輯 JSON。

預設參照 81 道場的點選走棋習慣。若習慣拖曳走棋，可在「配置與保存」勾選。

## 保存

草稿與局面庫保存在目前瀏覽器。換裝置、瀏覽器或網址不會自動同步，重要局面請下載 JSON。棋譜原文可以另外下載；切換步數會顯示棋譜原局面，請先保存修改過的教材圖。

## 目前範圍

支援 UTF-8／Shift-JIS KIF 主線、同、成／不成、打入、局面圖與部分常見讓子。尚未提供 KI2／CSA／SFEN、變化分支瀏覽、打步詰及千日手／勝負判定。錯誤棋譜不會覆蓋現有局面。

## 開發與檢查

`index.html` 是包含樣式、程式與圖片的完整單檔來源。後續修改請以它為準，避免編輯不同副本。

安裝 Node.js 後執行 `npm test` 或 `node test.cjs`，會檢查實際內嵌程式與棋譜解析、升變、吃子、持駒打入及非法輸入。

## 素材

棋盤與棋子使用空想曲線（KUUSOU-KYOKUSEN）素材，詳見 [THIRD_PARTY.md](THIRD_PARTY.md)。本專案不是 81 道場官方產品，沒有使用其圖片或聲音。
